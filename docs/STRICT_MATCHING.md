# Строгий отбор для нового поискового профиля

В форму создания и редактирования добавлен блок «Точность подбора»:

- **Обычный отбор** — прежнее поведение, значение по умолчанию.
- **Строгий: без немецкого** — нужно явное подтверждение отсутствия требования немецкого.
- **Строгий: без немецкого или до A1** — также допускается явно названный A1,
  если общая анкета человека подтверждает хотя бы этот уровень.

Настройка хранится в `SearchProfile.strict_match_mode`. Она не меняет общие языки,
правовой статус, другие профили или профиль по умолчанию. Миграция 0013 добавляет
старым профилям режим `off`; профиль для пользователя не создаётся.

## Как создать нужный профиль

Откройте **Профиль → Новый профиль** (`/profile/new`) и выберите строгий режим.
Задайте подходящие профессии, например Lagerarbeiter, Verpacker, Produktionshelfer,
Reinigungskraft, Auslieferungsfahrer. Введите Berlin, Neustrelitz, Neubrandenburg,
Rostock и радиус **Только эти города**. Отметьте открытые права B.
Остальные условия задайте по своей ситуации. Права не означают наличие своего автомобиля.

В общей анкете уже сохранённый уровень языка и §24 можно использовать без изменения.
Указание §24 не требуется в самом объявлении: фильтр проверяет право на работу
и несовместимые условия работодателя. Слова «принимаем украинцев» не доказывают,
что можно работать без немецкого.

## Что проверяется

Полное описание, ссылка на источник, подтверждённые профессия и география;
явное отсутствие требования немецкого или разрешённый A1; несовместимые требования
английского и распознаваемых других языков; категории для водительской работы;
обязательные дипломы, опыт и допуски, которые не подтверждены анкетой.
Неясные условия и условия, требующие проверки в обычном режиме, скрываются.
При выбранной форме занятости она должна быть подтверждена. При запрете самозанятости
нужны признаки работы по найму. Зарплата остаётся ориентиром, как написано в форме.

`Grundkenntnisse` без явно названного A1 недостаточно. `English only` при отсутствии
рабочего английского не проходит. Отрицания вроде «опыт не требуется» не считаются
обязательным опытом. Баллы ранжирования не могут отменить строгий отказ.

Причины сохраняются существующим механизмом скрытых результатов, с кодами `strict_*`.
Режим включён в JSON-экспорт поиска. При объединении источников положительное
языковое доказательство берётся только из полного текста, а противоречия — из всех текстов.

## Ограничения этой основы

Это детерминированные правила распознавания, а не гарантия трудоустройства или 100%
точности понимания любых формулировок. Проверка работодателем остаётся отдельным шагом.

BA, Careerjet, Adzuna и Jooble сейчас передают записи с `description_complete=False`.
Строгий режим скрывает такие записи. Отдельный загрузчик полных страниц в этой поставке
не добавлен; источники с полными описаниями могут пройти проверку. В результате поиск
может оказаться пустым — ограничения автоматически не ослабляются. Нет автоматического
обзванивания работодателей, отправки сообщений или создания пользовательских профилей.

## Локальный запуск и проверки

```powershell
Set-Location -LiteralPath 'C:\Users\tzvan\Desktop\SmartJob_ SearchAgent'
$env:DATABASE_URL = 'sqlite:///smartjob.local.sqlite3'
.\.venv\Scripts\python.exe -B -m alembic upgrade head
.\.venv\Scripts\python.exe -B -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

Перед запуском остановите старый сервер, если он занимает порт 8000.
Ожидаемый результат: в новой форме видны три режима; старые профили остаются в обычном
режиме; новый профиль появляется только после отправки формы пользователем.
