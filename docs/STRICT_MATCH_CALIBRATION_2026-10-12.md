## Прогоны

Выполнены живые запросы Helfer, Lagerhelfer и Fahrer Klasse B по Berlin, Neustrelitz,
Neubrandenburg и Rostock. Глубина диагностики — первая страница до 50 записей на запрос.
BA, Careerjet, Adzuna ответили; Jooble вернул ошибки. Ответы сохранены локально для
повторяемого сравнения правил; персональные данные и ключи API в репозиторий не добавлены.

| Шаг на первых 451 записях | Кандидатов без жёсткого отказа |
| --- | ---: |
| Исходные правила | 0 |
| Неполное описание переведено в предупреждение | 0 |
| Дополнительно неясный договор переведён в предупреждение | 0 |
| Дополнительно дата начала оставлена на проверку | 0 |
| Дополнительно неизвестный язык оставлен на проверку | 255 |

255 включали медицинских помощников и продавцов по слову Helfer. Поэтому введена
проверка профессии по заголовку, минимального текста и раздела требований. Затем
ручная проверка обнаружила нераспознанные требования немецкого, опыта и другой город
фактической работы. Эти случаи снова стали жёсткими отказами и покрыты тестами.

После трёх запросов собраны 819 уникальных записей источников. Финальные правила отдельно
по записям дают 30 кандидатов на проверку и 789 отказов. Полный конвейер нормализации,
объединения дублей, фильтрации и ранжирования даёт 690 вакансий: **4 на проверку,
0 подтверждённых, 1 ниже порога оценки и 685 скрытых**. Объединение учитывает требования
из всех дублей, поэтому результаты по отдельным записям нельзя считать числом вакансий.
В этой ограниченной выборке все 4 кандидата находятся в Берлине. Это не утверждение
об отсутствии подходящей работы в остальных городах.

## Проверка объявлений

- **SYNERGIE, Lagerhelfer, Berlin-Rudow:** в [первичном объявлении](https://synergie.de/stellenanzeigen/lagerhelfer-m-w-d-berlin-rudow-12357/)
  прямо указано отсутствие языкового требования. Сменная работа, самостоятельный проезд.
  Это наиболее сильный кандидат; транспорт и дату выхода нужно согласовать.
- **PerZukunft, склад / упаковка:** [первичное объявление](https://www.perzukunft.de/job/helfer-in-lagerwirtschaft-transport-verpackung-1201610005562988)
  подтверждает Берлин, отсутствие обязательного опыта и смены. Требование языка не указано:
  остаётся на проверку, пригодность без немецкого не подтверждена.
- **flaschenpost, Lagerist / Lagerhelfer:** фрагмент содержит требования и обязанности,
  но не подтверждает допустимый язык. Полная страница работодателя недоступна без JS.
- **goReach, Lagerhelfer:** подходящие город и обязанности, начало требований видно
  во фрагменте; полную исходную страницу получить не удалось. Язык и договор не подтверждены.

Дополнительно проверены объявления, исключённые при калибровке: хороший немецкий у Tempton,
немецкий для общения у Berliner Kaffeerösterei, опыт ламинирования у Tabel, работа
в Kleinmachnow при метке Berlin. У PerZukunft встречаются противоречивые данные оплаты;
зарплату не следует считать подтверждённой на основании агрегатора.

Отсутствие упоминания §24 в вакансии не является отказом. Право на работу берётся
из общей анкеты; согласие конкретного работодателя и фактический допуск к выходу
этот поиск не подтверждает. Баллы — порядок выдачи, а не процент релевантности.

## Проверки и повторный запуск

2423 теста прошли; Ruff для изменённых Python-файлов без замечаний.
Автотесты покрывают разделение «подтверждено / на проверку», сохранение запретов,
чужие профессии, географию, язык, опыт и независимость профилей.

После обновления перезапустите приложение и выполните поиск из профиля №11.
Результаты нужно смотреть в группе «На проверку». Фильтры больше не ослабляются
автоматически при нулевой выдаче. Для подтверждённых результатов всё ещё требуется
достаточное положительное доказательство; гарантии 100% здесь нет.
